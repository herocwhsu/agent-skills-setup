# Code for Lecture 11: Making the Agent's Runtime Observable

This directory contains code and contract artifacts for Lecture 11:

- `runtime_logger.py`: Production-grade Python structured logger, trace and span context propagator, and deterministic automated root-cause / cascading failure diagnostic engine.
- `test_runtime_logger.py`: Comprehensive test suite verifying structured serialization, span propagation, failure diagnosis, latency detection, and comparison metrics.
- `sprint-contract.md`: Short-term pre-coding contract specifying sprint goal, "done means", explicit scope, verification standards, and exclusions.
- `evaluator-rubric.md`: Evidence-based 1–5 scoring rubric transforming subjective evaluations into reproducible assessments across grounding, citations, functionality, and coherence.
